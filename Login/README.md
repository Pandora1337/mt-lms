# Login
![Login Screen](https://github.com/Pandora1337/mt-lms/blob/main/Login/assets/login.png)

This is the first page the user sees. When navigating without a session cookie, the user is redirect here for authentication, then returns to the attempted page.  

Notice there is no way to register. Admin and Managers create user accounts for employee access.
